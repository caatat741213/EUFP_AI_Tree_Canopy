# In-Class Activity: Ethical Audit of Your AI Solution

## Learning Outcome Covered

**4.1** Analyze AI solutions from multiple lenses: accessibility, ethics, equity, privacy, security, sustainability, and well-being.

## Activity Overview

Students will evaluate their own completed AI project as if it were being reviewed for real-world deployment.

## Step 1: Project Reframing

- What problem does your AI solve?
- Who are the real users affected?
- What decisions does your AI influence?

## Step 2: Ethical Audit

Evaluate your project using the following lenses:

Accessibility, Ethics, Equity, Privacy, Security, Sustainability, Well-being.

| Lens | Key Questions | Your Analysis | Risk Level (Low/Med/High) |
|---|---|---|---|
| **Accessibility** | Can people with disabilities use it? |  |  |
| **Ethics** | Is the decision-making transparent and fair? |  |  |
| **Equity** | Does it introduce bias or discrimination? |  |  |
| **Privacy** | Is user data collected, stored, or misused? |  |  |
| **Security** | Can the system be attacked or manipulated? |  |  |
| **Sustainability** | Does it consume excessive resources? |  |  |
| **Well-being** | Does it impact mental/social health? |  |  |

## Step 3: Red Flag Identification

- 1 Critical Risk
- 1 Moderate Risk
- 1 Responsible Design Choice

## Step 4: Ethical Redesign

- What would you **change in your prototype** to reduce risks?
- What **additional features / controls** would you introduce?

Examples:

- Add explainability layer
- Introduce consent mechanism
- Bias monitoring dashboard
- Data anonymization

## Step 5: Final Verdict

Deploy / Deploy with Conditions / Do NOT Deploy

## Step 6: Final Verdict

**Each Team critiques the other’s system**

> “Would I trust this system if I were the user?”

> **“Would you take legal responsibility for this AI system?”**
